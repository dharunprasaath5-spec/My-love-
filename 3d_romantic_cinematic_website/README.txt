A UNIVERSE FOR YOU — 3D ROMANTIC CINEMATIC WEBSITE

RUN IT
1. Extract this ZIP.
2. Open the extracted folder.
3. Double-click index.html to open it in Chrome, Edge, or Firefox.
4. Click ADD HER PHOTO and select the picture. The image is previewed locally in your browser.
5. Scroll down to open the interactive letter and reach the coffee invitation.

PERSONALISE
- Open index.html in VS Code to edit the words.
- To show a photo by default, put it in assets/ and name it her-photo.jpg.
- The chosen photo is saved only in this browser/device using local browser storage. It is not uploaded to a server.

NOTES
- This is a static front-end project; no backend or installation is required.
- Internet access is needed for the Google Fonts. The animations and page still work without them using fallback fonts.
- The sound control is a placeholder; no audio plays.
- Please share the page respectfully and give her room to respond honestly.
